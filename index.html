🩺 Apple 健康同步設定

流程說明：
  1. 喺「捷徑」App：用「尋找健康樣本」讀步數／睡眠／飲水，再用「計算統計資料」攞總和。
  2. 用「文字」砌網址，格式係 …#HEALTH_SYNC:steps= ＋步數變數＋&sleep=＋睡眠變數＋&water=＋飲水變數。
  3. 想連體重：再加一個「尋找健康樣本」→ 體重（最新一筆），喺網址後面加 &weight= ＋體重變數。
  4. 唔好用 { } " 大括號／引號：iOS 會當佢哋係非法 URL 字元而食咗，結果就係而家咁「冇數據」。
  5. 頁面頂部出綠色橫幅，撳「同步數據」即更新當日紀錄；冇橫幅就可以用下面「📋 手動貼上數據」。
📋 手動貼上數據
貼上 HEALTH_SYNC:steps=6850&sleep=7.5&water=2200 或 HEALTH_SYNC:{"steps":6850} 再撳「解析並同步」。前綴可以漏，直接貼內容都得。
